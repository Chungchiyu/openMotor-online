# openMotor Online

A client-side web port (MVP) of [openMotor](https://github.com/reilleya/openMotor), the open-source
solid rocket motor internal ballistics simulator. Everything runs in the browser — there's no
backend; the physics engine is a from-scratch TypeScript port of openMotor's Python `motorlib`.

## Status: MVP

This covers a deliberately narrow slice of the original desktop app, chosen to validate the port
end-to-end before expanding scope:

- **Grain shapes:** BATES (analytic) and Star Grain (via a hand-rolled fast marching method +
  marching squares, standing in for `scikit-fmm` and the project's Cython contour routine).
- **Propellant:** a small built-in preset list, not the original's full propellant database editor.
- **Persistence:** browser `localStorage` autosave, plus manual JSON export/import. No `.ric`/YAML
  file compatibility, DXF import, BurnSim import/export, ENG export, or undo/redo yet.

See `src/physics/` for the engine and `src/ui/` for the interface. The physics port is
regression-tested against golden values produced by running the actual Python `motorlib` on
openMotor's own bundled test fixtures (`src/physics/__fixtures__`, generated by a one-off script —
not part of this app) — see `src/physics/__tests__/motor.reference.test.ts` for how tight a
tolerance each grain type is held to and why.

## Development

```bash
npm install
npm run dev      # start the dev server
npm run build    # type-check + production build
npx vitest run   # run the physics engine test suite
```
